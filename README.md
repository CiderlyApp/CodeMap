# CodeMap 🧭

**CodeMap** — аналитический инструмент для исследования графа зависимостей исходного кода, выявления кандидатов на рефакторинг и формирования очищенного контекста кодовой базы для языковых моделей (LLM).

Инструмент позволяет выбрать файл в проекте, автоматически разрешает входящие и исходящие связи (импорты, экспорты, вызовы), визуализирует полученную топологию и упаковывает взаимосвязанные компоненты в компактный бандл, готовый для вставки в ChatGPT, Claude, DeepSeek или локальные модели.

---

## 🎯 Назначение и решаемые задачи

При разработке с помощью LLM передача изолированного файла часто приводит к галлюцинациям модели из-за отсутствия контекста типов, интерфейсов и связанных сервисов. Ручной сбор файлов занимает время, а отправка проекта целиком расходует лимиты токенов.

**CodeMap решает эти проблемы:**
1. **Точечный контекст:** автоматически находит транзитивное замыкание зависимостей выбранного файла (двунаправленный граф).
2. **Очищенный вывод:** формирует форматированный дамп кода с разделителями `// FILE: path` без избыточных служебных тегов.
3. **Контроль архитектурного долга:** подсвечивает проблемные модули с высоким числом строк кода (LOC).
4. **Автономность:** работает как через серверный FastAPI-бэкенд, так и полностью локально в браузере через File System Access API без передачи исходного кода на сторонние серверы.

## ✨ Основные возможности

* **Анализ зависимостей трех экосистем:**
  * **Python:** анализ AST (`ast.parse`) с поддержкой относительных (`from ..service import get_user`) и абсолютных импортов проекта.
  * **JavaScript / TypeScript:** парсинг ESM (`import/export`), CommonJS (`require`), динамических импортов и алиасов корня (`@/`, `~/`).
  * **Dart / Flutter:** разбор директив `import`, `export`, частей библиотек `part 'model.g.dart'`.
* **Интерактивный граф связей:**
  * Автоматическая кластеризация файлов по папкам без взаимных перекрытий блоков.
  * Трассировка сглаженных кривых Безье, привязанных к периметру карточек файлов.
  * Цветовая дифференциация типов связей (`import`, `from_import`, `export`, `test`, `dynamic`).
* **Адаптивный сборщик контекста для LLM:**
  * Экспорт одиночного файла (`📄 Только файл`) или полного транзитивного бандла (`📦 Бандл`).
  * Ручное закрепление произвольных файлов в бандле (`📌`) прямо из дерева или инспектора.
  * Исключение ненужных зависимостей кликом по элементам списка.
* **Идентификация файлов-сирот (Orphan files):**
  * Фильтрация файлов без связей (`Все файлы`, `Скрыть файлы-сироты`, `Только файлы-сироты`).
* **Метрики рефакторинга:**
  * Настраиваемые пороги строк кода (Warning / Critical LOC).
  * Выделенный виджет *Candidates for Refactoring* с сортировкой по размеру файлов.
* **Встроенный просмотрщик кода:**
  * Быстрый просмотр сырого содержимого файла с подсчетом строк без открытия IDE.
* **Гибкая фильтрация:**
  * Настройка масок исключения файлов (`*.g.dart`, `*.min.js`, `*.lock`) с поддержкой wildcard-символов (`*`, `?`).
